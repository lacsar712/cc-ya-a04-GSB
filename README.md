# 风机偏航对中台

现场技师在顶栏「主备编码器双通道对拍入队台」专页登记机组的主/备编码器绑定与主备差值门槛；报数时一次提交主、备两路偏航误差，两路读数对拍一致（|主−备| ≤ 门槛）才许入队，超门槛则整单退回并记入拒收样例总览。入队记录由后台 worker 用数据库行锁认领，按两路均值与 ±1.5° 阈值写入「合格」或「偏航超差」。前端为 Lit 组件 + Vite，接口为 Quart + Hypercorn。

## 双通道规则

- **对拍入队**：主路、备路两路读数必须一次提交；|主路−备路| 超过绑定登记的差值门槛，整单退回（HTTP 400），原因写明「双通道超差」，并登记到拒收样例总览，不产生队列记录。
- **绑定随单冻结**：入队/拒收时把机组编号、主路编号、备路编号、门槛、两路读数、差值、均值全部快照到单据上；事后修改登记表不影响旧单。
- **入队与冻结同一事务**：行锁读绑定 → 对拍 → 冻结快照写入队列，一笔事务提交；`yaw_logs` 上对 `binding_id` 的 pending 部分唯一索引兜底，两人并发争抢同一绑定至多一笔成功（另一笔 409）。同一绑定上一笔待处理结完后才允许再报。
- **权限**：技师（writer）可登记/修改绑定、可报数；观察员（reader）可查看绑定、两路读数、差值与拒收样例，但不能改绑定，也不能报数。

## 验收

1. 技师登录后进入「主备编码器双通道对拍入队台」，登记一号机绑定：主路 `ENC-1-A`、备路 `ENC-1-B`、差值门槛 `1.0`（两个勾选框不算专页——本页含绑定登记表、绑定总览、拒收样例总览）。
2. 在「对拍入队」页选择该绑定，主路报 `0.8`、备路报 `0.9`：差值 0.1 ≤ 1.0，记录进入「待处理」（入队均值 0.85），数秒内 worker 判定为「合格」。
3. 主路报 `0.8`、备路报 `2.5`：差值 1.7 > 1.0，整单退回，提示「双通道超差……」，拒收样例总览新增一条；队列表不新增记录。
4. 该绑定存在待处理记录时再报（或两人并发同报）：返回 409，至多一笔入队。
5. 在登记页把绑定改为新编号/新门槛（如 0.5）：旧入队单与旧拒收单仍显示当时冻结的编号与门槛；新单按新门槛、新编号冻结。
6. observer 登录：可看绑定、两路读数、差值、拒收样例；没有登记/修改表单与报数表单，直接调写接口返回 403。
7. 种子数据：机组 W01 两路 0.4/0.4 结论「合格」；机组 W07 两路 3.2/3.2 结论「偏航超差」。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | - | 登录取 token |
| GET | `/api/bindings` | 登录 | 绑定登记总览 |
| POST | `/api/bindings` | 技师 | 登记主备绑定（机组/主路/备路编号唯一） |
| PUT | `/api/bindings/<id>` | 技师 | 修改绑定（只影响新单） |
| POST | `/api/logs` | 技师 | 提交 `binding_id` + 主备两路读数；对拍一致 201 入队，超差 400 退回，并发冲突 409 |
| GET | `/api/logs` | 登录 | 对拍入队记录（含冻结快照与差值） |
| GET | `/api/rejected` | 登录 | 拒收样例总览 |

## 技术栈

- 后端：Quart、psycopg、`worker.py`（`FOR UPDATE SKIP LOCKED`）、Hypercorn
- 数据库：PostgreSQL 16；部分唯一索引 `yaw_logs_one_pending_per_binding`
- 前端：Lit、TypeScript、Vite；顶栏 hash 路由（对拍入队 / 双通道对拍入队台专页）；生产镜像内 nginx 反代 `/api`
- 镜像源：DaoCloud 基础镜像、清华 PyPI、npmmirror npm
