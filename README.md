# 风机偏航对中台

主备两路编码器读数须对拍一致才许入队。技师在顶栏「主备编码器双通道对拍入队台」专页登记机组的主路/备路编码器编号与差值门槛；随后一次提交主备两路偏航误差，差值绝对值超门槛即整单退回并写明「双通道超差」，否则入队待处理，后台 worker 按主路读数 ±1.5° 阈值写入「合格」或「偏航超差」。

- 主备绑定关系随单冻结：工单落库时快照主路/备路编号与门槛，事后改登记表不影响旧单。
- 入队与绑定冻结并入一笔事务：两人并发争抢同一绑定，至多一笔成功（其余 409）。
- 观察员可看绑定与差值，不能改绑定也不能报工单。

前端为 Lit 组件 + Vite，接口为 Quart + Hypercorn。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/bindings | 绑定列表（含冻结状态），登录即可 |
| POST | /api/bindings | 登记绑定（技师）；同机组重复登记 409 |
| PUT | /api/bindings/<id> | 修改登记表（技师）；不影响旧工单快照 |
| GET | /api/orders | 工单列表（含差值与绑定快照），登录即可 |
| POST | /api/orders | 提交双通道工单（技师）：超门槛整单退回（双通道超差）；绑定已冻结 409；未登记 400 |

## 验收

1. 种子数据：W01 主路 0.4° 结论「合格」；W07 主路 3.2° 结论「偏航超差」；W03 差值 2.3° 超门槛，状态「退回」、结论「双通道超差」并出现在拒收样例总览；W05 绑定空闲可入队。
2. 先绑一号机主备（如门槛 1.0°），再报主路 0.8° 与备路 0.9°：差值 0.1° 未超门槛，工单进「待处理」，绑定随单冻结，数秒内 worker 给出「合格」。
3. 再报主路 0.8° 与备路 2.5°：差值 1.7° 超门槛，整单退回并写明「双通道超差」，出现在入队台专页的拒收样例总览。
4. 修改一号机绑定登记表（如改门槛），旧工单仍显示原快照门槛。
5. 两名技师并发提交同一绑定，至多一笔入队成功，另一笔 409。
6. observer 可查看绑定与工单差值，无登记/提交表单，写操作返回 403。
